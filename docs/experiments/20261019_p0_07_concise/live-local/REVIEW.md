## 具体失败证据

- run-1 / run-2 的 NP-2 声称已有文献讨论或支持“图摘要加速训练、减少计算资源”。其唯一卡片摘录只有图摘要综述的范围，没有该训练结论，Reviewer 也没有完成此点比较。
- run-1 / run-2 的 NP-3 称“已有文献提出/涉及基于图摘要的分布式图神经网络训练框架”。绑定文献实际题名为 *Deep Reinforcement Learning on Item-Compatibility Graphs for One-Dimensional Bin Packing*；当前摘录只支持一维装箱的图强化学习框架，不支持这一归属。原历史 Reviewer 本身也有摘录与解释不一致，未重跑 Reviewer，不能把这类问题全归因于本轮 prompt。
- run-2 的 NP-4 将“当前没有可核验证据”扩大为“具体实现细节尚未有文献详细描述”；没有证据可以证明整个文献范围的缺失。
- run-3 的卡 `card_5665d0bf4908499d6b5a832f` 归属 NP-3；两次响应都把它放入 NP-1 的 counter_card_ids，绑定校验均报 `cross-point reference`。该组不产生展示报告，不将旧兜底冒充真实生成结果。
- run-4 的 NP-1 在没有有效卡、Reviewer 未裁定的情况下写出“这在现有文献中是创新之处”，并称现有文献尚无直接针对大规模时序图的方法。其余三点也生成了没有文献依据的比较。这是内容失败，即使 JSON 和保留的结构化 verdict 均通过校验。
- run-3 原始 limitations 仍复述运行错误和预算限制，表明 prompt 未完全阻止技术说明；绑定层不直接发布模型 limitations，因此它未进入正式报告。

核查依据限于冻结输入与实际输出，没有重新审阅外部论文全文或认证科学新颖性。后续 prompt 调整应重点明确“目标论文自述”和“对照文献证据”的归属、未知不等于文献不存在、无证据不得作创新判断，以及逐点卡片归属。当前结果不足以将本地 7B 的综述直接视为可交付结论。
